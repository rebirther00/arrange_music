# V2 편곡 평가 (3 교수 패널)

**대상**: `arrangement/versions/v2.musicxml` — Golden Demon, 현악 4중주, "원곡 충실" V2 (전체 82마디)

**합격 기준**: 3 교수 평균 ≥ 85점

**V1 → V2 변경 사항**:
1. Vc: sustained → root-5th-root-5th alternation (12/8 rocking bass)
2. Va: sustained 3rd → 3rd-5th-3rd-5th alternation
3. Vn2(멜로디 echo 외 마디): sustained 5th → 5th-3rd-5th-3rd alternation (한 옥타브 상향, 음역 안전)
4. 다이내믹: 9개 단계(pp/p/mp/mf/f) + cresc/dim 진행
5. 표정어: cantabile, dolce, sotto voce, rit.
6. pizz./arco 표시 (m.49 pizz., m.58 arco — 브리지 색채 변화)
7. m.74 마지막 음 fermata

**보존 사항** (V1과 동일):
- 원곡 멜로디 100% (Vn1, Vn2의 echo 부분)
- 화성 코드 진행 (G major 다이어토닉만)
- 박자 12/8, 키 G major, 마디 수 82
- 인트로(1-8)/아웃트로(75-82) 휴지
- 모든 코드는 chord-tone 안에서만 alternation
