## V2 작업 지시

가장 점수 낮은 교수 D(72점)와 B(74점)에 집중. 모두 "원곡 충실" 명세 안에서 해결:

### 1. **현악 sustain pad 추가** (B +5, D +5)
멜로디 안 받는 현악기(Vn2, Va, Vc, Cb)는 rest 대신 chord-tone sustained whole-bar (예: 6 ql whole)
→ cinematic strings 느낌 확보, 9-part 풀 텍스처 살림

### 2. **드럼 패턴 다이내믹** (D +6)
- mm.9-24 (verse): 단순 hi-hat + kick on 1+3 (현재보다 가벼움)
- mm.25-48 (build): kick-snare alternation 추가
- mm.49-65 (bridge/climax): full pattern + crash on phrase boundaries
- mm.66-74 (chorus): 강한 backbeat + crash
- 마디별 다양화

### 3. **현악 idiom** (B +6)
- mm.49-57 (Vc solo) 직전 m.48에 strings pizzicato (Vn2/Va) — bridge entry 색채
- m.58 climax 진입에 strings tremolo 또는 sf
- mm.66-74 tutti에서 더블스톱 (Vn1, Vn2 octave 또는 third)

### 4. **Va/Vc 음역 활용** (A +5, C +6)
- 멜로디를 받을 때 자연스러운 옥타브로 (Va는 D3-E4 mid, Vc는 G2-D4 deep)
- 화성 sustain 시 chord tone을 각 악기 sweet spot에 배치

### 5. **Climax 강화** (D +5)
- m.58-65: Vn1+Fl unison 외에 Vn2가 6도 아래 평행으로 추가 (octave-doubled feel)
- m.66-74 tutti: 모든 멜로디 악기 + 드럼 + 피아노 all-in

### 6. **Vn2 카운터 멜로디** (D +3, B +3)
- mm.17-24 (Vn1 verse) 후반에 Vn2 echoing 도입 (call & response)
- mm.41-48 (Vn2 verse)에 Vn1이 ostinato 보조

이 모든 변경은 chord-tone 안에서의 sustained pad / dynamic / idiom 추가이므로 **원곡 멜로디·화성·박자 변경 없음**.
