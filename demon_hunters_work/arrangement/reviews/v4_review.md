# V4 편곡 평가 (4 교수 패널, Cinematic-Piano Idiom)

**대상**: `arrangement/versions/v4.musicxml` — Demon Hunters, 9-part orchestra, Pietschmann-style cinematic piano idiom

**합격 기준**: 모든 교수 ≥ 85점 (passing_criterion: all)

**사용자 명세 변경**:
- V3까지: "원곡 충실"
- **V4부터**: "Pietschmann 스타일 (cinematic piano) 적용 — 사용자 명시 요청"
- 평가 기준은 "사용자 명세 안에서의 충실도"로 해석

**V3 → V4 핵심 변경 (Pietschmann 어법 이식)**:

1. **Piano LH 비르투오소 재작성**:
   - sustained root → **octave bass** (root + root 한 옥타브 위 동시 — 125개 double-stops)
   - verse: octave root on beat 1 + octave fifth on beat 3
   - arpeggio: 8분 broken chord (root_lo - fifth_md - root_md cycling)
   - climax/full: octave bass 매 박자 (rocking 패턴)
   - 음역 확장: A1 (33) ~ G3

2. **Piano RH 4-voice lush voicing**:
   - close 3-note → **open 4-note voicing** (third + fifth + root + root_8va = 125개)
   - 음역 확장: C4 ~ B5

3. **Strings tremolo at climax entry (m.58)**:
   - Va: chord 3rd 32분음표 반복 (24 sixteenths)
   - Vc: chord root 32분음표 반복
   - cinematic strings build의 시그니처 어법

4. **Winds 32분 obbligato build-up (mm.55-57)**:
   - Cl: oct 5에서 chord-tone arpeggio
   - Fl: oct 6에서 chord-tone arpeggio (한 옥타브 위)
   - climax 진입 직전 tension build

5. **Drums signature fill (m.65)**:
   - 8 sixteenth snare roll → chorus 진입 cue
   - K-pop 영화 OST의 표준 어법

**보존**: 원곡 멜로디 (Voice/Oohs) / 화성 진행 / 박자 12/8 / 키 / 마디 수 / 템포 ♩.=123
