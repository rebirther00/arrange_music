# V2 편곡 평가 (4 교수 패널)

**대상**: `arrangement/versions/v2.musicxml` — Demon Hunters, 9-part ensemble V2

**합격 기준**: 모든 교수 ≥ 85점 (passing_criterion: all)

**V1 → V2 변경 사항**:
1. **String sustain pad**: Vn2/Va/Vc가 멜로디 안 받는 마디에 chord-tone whole-bar (cinematic strings)
2. **Counter-line dialogue**: mm.17-24 Vn2 echo (chord 5th pulse), mm.41-48 Vn1 counter (chord 3rd pulse)
3. **Drums 5-stage dynamic**: verse(mm.9-24) → build(25-48) → bridge(49-57) → climax(58-65) → chorus(66-74), crash on m.58/62/66/70
4. **Pizzicato idiom**: m.41 Vn2 pizz., m.49 arco
5. **Climax octave doubling**: mm.58-65 Vn2 = 멜로디 6도 아래 (double choir effect)
6. **Tutti chorus**: mm.66-74 Vn1+Vn2+Fl+Cl 모든 멜로디 악기 unison
7. **Vn1 octave double-stops**: mm.66-74 chorus tutti 클라이맥스 (string idiom 강화)
8. **다이내믹 arc**: pp/p/mp/mf/f/ff 6단계 + 표정어(cantabile, leggiero, espress., soaring 등)

**보존 사항** (V1과 동일):
- 원곡 멜로디(Voice/Oohs) 모든 음표 보존
- 화성: Piano RH/LH 원본 그대로
- 박자 12/8, 키(1#), 마디 수 82
- 인트로(1-8)/아웃트로(75-82) 휴지
