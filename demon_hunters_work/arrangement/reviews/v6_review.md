# V6 편곡 평가 (4 교수 패널, Layered Intro/Outro)

**대상**: `arrangement/versions/v6.musicxml` — V5 + 인트로 layered build + 아웃트로 layered decay

**합격 기준**: 모든 교수 ≥ 85점 (passing_criterion: all)

**V5 → V6 단일 핵심 변경**:
- 인트로(mm.1-8) / 아웃트로(mm.75-82)에서 다른 악기들이 piano와 함께 화음을 쌓아 점진적 build / decay 형성
- Piano 자체(원곡 ostinato + chord)는 V5 그대로 유지

**Layered Build (mm.1-8)**:
| 마디 | 추가 악기 | 다이내믹 |
|------|-----------|---------|
| 1-2 | Piano (V5 ostinato + chord) | pp |
| 3-4 | + Vc (root) + Cb (root) | pp |
| 5-6 | + Va (3rd, inner voice) | pp |
| 7-8 | + Vn1 (5th high) + Vn2 (3rd) + Cl (root oct 5) | p (anticipation) |

**Layered Decay (mm.75-82)**:
| 마디 | 잔존 악기 | 다이내믹 |
|------|-----------|---------|
| 75-76 | Full ensemble (chorus aftermath) | mp |
| 77-78 | – Vn1 + Fl (highest layers leave) | p |
| 79-80 | – Vn2 + Cl | p→pp |
| 81 | Only Cb + Piano | pp |
| 82 | Piano alone (morendo) | pp |
