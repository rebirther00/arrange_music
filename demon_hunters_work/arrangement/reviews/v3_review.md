# V3 편곡 평가 (4 교수 패널, Director's Cut)

**대상**: `arrangement/versions/v3.musicxml` — Demon Hunters, 9-part orchestra V3

**합격 기준**: 모든 교수 ≥ 85점 (passing_criterion: all)

**V2 → V3 핵심 변경 (음악감독 시점)**:

1. **텍스처 분리 (Role separation)**: 한 악기 = 한 역할. 멜로디 / 화성쿠션 / 베이스 / 리듬 명확히 분리.
2. **Piano 완전 재작성** (연주 가능 형태):
   - LH: chord root-5th alternation (4 dotted quarters), 음역 C2-G3
   - RH: close-position 3-note triad voicing, 음역 C4-G5
   - 멜로디 doubling 절대 금지 → 멜로디 명확히 부각
   - 양손 stretch 5도 이내 (전부 single-position 운지)
3. **Strings sustain pad 음역 강하**: Vn2 G3-A4 / Va C3-G3 / Vc C2-D3 / Cb C2-D2
   → 멜로디 영역(G4-A6)과 한 옥타브 이상 분리, 멜로디 부각
4. **Drums sparse 5-stage**: verse(kick on 1+3, hat 12분 절반만) → bridge(minimal kick+snare) → pre-chorus build → climax(full+crash) → chorus(full+ride+crash)
5. **Counter-melody/obbligato**:
   - mm.17-24 Cl 16분 obbligato (chord-tone arpeggio over Vn1 verse)
   - mm.41-48 Fl 16분 obbligato (over Vn2/Va octave melody)
6. **수직 어울림 (vertical layering)**:
   - mm.25-32: Fl + Cl 평행 3rd (winds duo)
   - mm.41-48: Vn2 + Va octave doubling (string section octaves)
   - mm.58-65: Vn1 + Fl unison + Vn2 lower-6th (3-part climax)
   - mm.66-74: 4-part harmony chorus (Vn1 octave double-stops + Vn2 −6th + Fl + Cl −5th)
7. **오케스트라 어법**: pizz./arco (Cb), divisi (chorus), 더블스톱 (Vn1 chorus), 평행 3rd/6th/8va

**보존 사항**: 원곡 멜로디(Voice/Oohs) 음표 / 화성 진행 (G major diatonic) / 박자 12/8 / 키 / 마디 수 82 / 인트로·아웃트로 / 템포 ♩.=123
